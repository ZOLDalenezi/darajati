# درجتي · Darajati

تطبيق بايثون يساعد طالب الثانوية الكويتية على فهم الدرجات والتخطيط للتحسين.

## التشغيل

Python 3.12، ثم:

```text
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## المزايا

- الحاسبة التقليدية وحاسبة اللائحة الشاملة 2026.
- فترة واحدة أو متوسط الكورسين بعد تحويل كل كورس.
- محاكاة خصم، فرص تحسين، وهدف للنسبة.
- بطاقة نتيجة عربية مع معاينة وحفظ اختياري.
- مشعل: تحليل محلي فوري وGemini اختياري بانتظار محدود.
- حاسبة التراكمي 10% / 20% / 70%، ودليل مصادر.

## النشر المجاني

1. ارفع ملفات التطبيق إلى مستودع GitHub، باستثناء secrets.env وأي secrets.toml حقيقي.
2. سجّل في https://share.streamlit.io باستخدام GitHub.
3. Create app، اختر المستودع والفرع main والملف app.py.
4. من Advanced settings اختر Python 3.12. ضع مفتاح Gemini في Secrets فقط، بالصيغة الموجودة في .streamlit/secrets.toml.example.
5. Deploy، ثم افتح الرابط من هاتف على شبكة مختلفة. أنشئ QR للرابط العام بعد نجاحه.

لا تحتاج دومينًا مدفوعًا. الاستضافة مجانية بحسب Streamlit Community Cloud؛ Gemini له حدود مجانية وحساباته المدفوعة منفصلة. الحسابات والتحليل المحلي يعملان بلا مفتاح.

## مصدر الحساب الجديد وحدوده

وزارة التربية: https://www.moe.edu.kw/shorturl/taleem2026-doc

راجعت الجداول بتاريخ 19 سبتمبر 2026: ص126 للفترات، ص127 لشرائح GPA والمعادلة، ص128 لمكونات الدرجة، ص132 لأوزان المواد، ص134 للتراكمي.

التصنيف على الحد الأدنى للشريحة دون تقريب الكسور. تؤخذ شريحة كل مادة قبل الوزن. في العام الكامل يحوّل كل كورس ثم يؤخذ المتوسط. تطبّق المعادلة المنشورة (GPA+1)×20 حتى للشريحة F؛ لذلك وجود نسبة محولة لا يدل على اجتياز المادة. ليست هذه خدمة رسمية، ولا تحسب القرارات الإدارية والغياب أو تثبت النجاح. نظام المسارات له لائحة مستقلة ولا تتوفر حاسبة وحداته في هذه النسخة.

## الخصوصية

لا توجد قاعدة بيانات لدرجات الزوار. تُحفظ حالة التفاعل في الجلسة، مع تخزين مؤقت لبطاقة النتيجة في ذاكرة الخادم. اسم البطاقة مستبعد من طلب Gemini. إذا فعّل المستخدم المحادثة الخارجية، ترسل الرسائل والدرجات إلى Google؛ لا يدخل معلومات شخصية حساسة. زر بدء تجربة جديدة يمسح حالة الجلسة.
